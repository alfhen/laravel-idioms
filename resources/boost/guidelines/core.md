## Laravel idioms

- Activate the `laravel-idioms` skill whenever you write, edit, review or refactor code in this Laravel app (controllers, form requests, models, queries, jobs, caching, Blade, Filament, tests), together with `laravel-best-practices`. The two complement each other: `laravel-best-practices` holds the broad rules, and `laravel-idioms` holds concrete idiom rules, Laravel 13 / Filament 5 / Pest 5 API specifics and a mandatory "Before you finish" checklist.
- Go through the `laravel-idioms` "Before you finish" checklist before reporting any code change as done.
- To audit this codebase or produce refactor suggestions, activate `laravel-idioms` and follow its audit mode.
