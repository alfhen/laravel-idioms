## Laravel idioms

- Activate the `laravel-idioms` skill whenever you write, edit, review or refactor code in this Laravel app (controllers, form requests, models, queries, migrations, jobs, schedules, Artisan commands, uploads, HTTP calls, inbound webhooks, events and mail, caching, Blade, Livewire, Inertia, Filament, error handling and logging, dates and money, Spatie permission, query-builder, data, model-states and medialibrary code, tests), together with `laravel-best-practices` (and `testing-best-practices` when writing tests). `laravel-best-practices` holds the broad rules; `laravel-idioms` holds concrete idiom rules, Laravel 13 / Filament 5 / Pest 5 API specifics and a mandatory "Before you finish" checklist.
- Precedence: the project's `.ai/rules` and skills shipped by installed packages (such as `laravel-permission-development`, `medialibrary-development`, `cashier-stripe-development`) decide that project's conventions and the package's API specifics. `laravel-idioms` wins wherever following them would leave a correctness or security defect.
- Go through the `laravel-idioms` "Before you finish" checklist before reporting any code change as done.
- To audit this codebase or produce refactor suggestions, activate `laravel-idioms` and follow its audit mode.
